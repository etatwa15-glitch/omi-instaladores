# Descargas de OMI

Este repositorio distribuye las compilaciones de OMI. No contiene el código fuente.

En la [versión más reciente](https://github.com/etatwa15-glitch/omi-instaladores/releases/latest) encontrarás:

- **Windows de 64 bits:** `OMI-Instalar.exe`.
- **Mac con chip Apple (M1 o posterior):** `OMI-macOS-arm64.zip`.
- **Mac con procesador Intel:** `OMI-macOS-x64.zip`.

En Mac, extrae el ZIP y mueve `OMI.app` a Aplicaciones. Las compilaciones de Mac todavía no están firmadas ni notarizadas y se actualizan descargando una nueva versión manualmente. Los archivos `RELEASES` y `.nupkg` son para la actualización automática de Windows.
